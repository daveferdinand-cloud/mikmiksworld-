# Mika's World

The live site for **mikmiksworld.com** — built from Mika's own notebook wishlist:
nine places (Art & Sketch Studio, Craft Idea Station, House Crafts, Story Centre,
Recipe Lab, Top 3 Songs, Gallery of Books, Hello Kitty Things & the Plush Shelf,
Cousins), her Top 50 no-cook recipes, self-drawing sketch lessons, a story
publishing centre, and her three favourite Taylor Swift songs as piano versions.

## Live deployment

- Hosted on Vercel (project `mikmiksworld`), deployed from this exact source.
- Production: https://mikmiksworld.vercel.app → https://mikmiksworld.com (DNS at GoDaddy)

## Source layout

- `index.html` — the entire site (markup, styles, behaviour) in one file.
- `assets/` — the 17 painted scene/portrait images the page references
  (hero, place scenes, doors, plush and cousin portraits). The images live with
  the Vercel deployment; this repository currently holds the page source.

Mika's likeness across the site is locked to one canonical portrait of her,
supplied and approved by her family. No real photographs of Mika appear on the site.
